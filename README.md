## Cara Menjalankan

### Laravel
1. Masuk ke folder project.
2. Jalankan `composer install`.
3. Salin `.env.example` menjadi `.env`.
4. Atur konfigurasi database sesuai project.
5. Jalankan `php artisan key:generate`.
6. Siapkan database sesuai petunjuk project.
7. Jalankan `npm install`.
8. Jalankan `php artisan serve`.
9. Jalankan `npm run dev` di terminal lain.

### Next.js
1. Masuk ke folder project.
2. Jalankan `npm install`.
3. Jalankan `npm run dev`.
4. Buka http://localhost:3000.

Project lainnya dijalankan sesuai instruksi
pada masing-masing folder.
